## Third-party code

This plugin is a Revenge Next port of **Hide call buttons** by John
([janisslsm](https://github.com/janisslsm), Discord ID `780819226839220265`), from
[janisslsm/vdplugins](https://github.com/janisslsm/vdplugins) (`plugins/HideCallButtons`).

It is a **derivative work**: the idea, the surfaces it changes (profile, DM header, voice
channel) and the settings for each are from the original. How the buttons are found has since
been rewritten. Since 1.3.1 each screen recognises its controls by their place in their own row,
not by the icon or asset-id comparison the original used.
