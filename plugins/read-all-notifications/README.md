# Read All Notifications

Mark unread server channels as read with a button in the server list, placed under your Favorites or Direct Messages.

| | |
| --- | --- |
| Plugin id | `dev.nexza.read-all-notifications` |
| Version | 1.0.2 |
| Author | unalivin |

## Install

1. Open [`version/read-all-notifications/`](../../version/read-all-notifications) and download the ZIP.
2. Hand it to Valenced's plugin installer.
3. Turn it on in Settings → Plugins.

## How it works

The button sits in the server list:

- **Favorites on** → button appears under the **Favorites** row.
- **Favorites off** → button appears under **Direct Messages**.

Pressing it marks every unread channel across all your servers as read.
